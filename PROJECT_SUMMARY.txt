================================================================================
INSTALLATION STEPS
================================================================================

1. Import Database:
   mysql -u root -p < database/heritage_db.sql

2. Configure Database Connection:
   Edit config/database.php with your credentials

3. Set Permissions:
   chmod 755 uploads/products uploads/logos

4. Access Application:
   http://localhost/Heritage/
